01 · 路线图与里程碑

一句话：大 RPG 不是一次做出来的，是一次次发布出来的。你想要的"长线更新"有一个硬前提——得先有一个已经上线的东西。没有上线的东西，就没有"更新"这回事。

一、四阶段全貌

步是什么规模预计时间这一站的意义
A社团练手（2–3 个小游戏）每个 1–7 天一个学期，课余学会"把东西做完"；认识人；不占用共同项目
B序章（独立可发布）60–120 分钟约 1.2–2 年上线、拿到真实反馈、跑通发布流程
C长线更新每次 +30–60 分钟每 3–6 个月一更"长线更新"从这里正式开始
D完整 RPG多岛、多章节、多结局第 3 年起一路更出来

A 和 B 可以并行：A 是你的成长通道，B 是你们的共同项目。社团学到的东西立刻用到 B 上。

二、阶段 B（序章）的内部阶段

这一层是能力阶梯——每个小阶段都有独立可验收的产出。

阶段做什么投入周期验收标准
第 0 步跟完一个教程小游戏，能打包30–50h2–3 周能独立打包 + 看懂 80% 代码
S1 画面做出「一张截图」（HD-2D 观感）20–40h2–3 周别人看了会说"像八方旅人那种"
S2 走动角色移动 + 碰撞 + 相机跟随30–50h3–4 周能在场景里自由走动
L0 翻面按键触发翻面（换贴图/调色/光照/显隐地标）40–80h1–2 个月按一个键，世界明显变了；能录 15 秒视频给人看
L1 规则闭环平衡度单轴 + 采集 + 指令式战斗 + 死亡复活100–180h2–4 个月3 个人玩过，能说出"这个数值是什么意思"
L2 微切片1 岛 2 状态 + 翻面窗口事件（2 解） + boss + 结局200–350h4–7 个月3 个外人通关，且能复述这个世界的规则
L3 序章3 个 NPC + 小聚落 + 节点式航行 + 船改造 + 音频 + 打磨300–500h6–10 个月60–120 分钟完整流程，可打包分发，10 个陌生人玩过

累计：约 1000–1900 小时 ≈ 1.2–2 年（按 15–19 小时/周）。

每一站都是可以停下来的完整成果。 S1 的那张截图本身就是一个成果；L1 做完就有一个"能玩一会儿"的东西。

三、序章到底包含什么（这就是第一款要发布的东西）

规模：60–120 分钟，可通关。

#内容说明
11 座岛，2 个状态（骨架复用 + 分层改绘）翻面机制完整可玩
2"平衡度"单轴 + 自身失衡值能量同轴落地
31 个可玩角色 + 指令式战斗 + 3–4 个技能已定
41 次翻面窗口事件，含 2 种解法（撤离 / 催化）道德抉择的核心体验
5航海日志 + 海图即锚定知识型进度作为主轴
6死亡 → 复活（含代价）世界观独有机制
71 个 boss + 2 个结局 + 1 个失败结局失败结局成本≈0
82 个 NPC 出场，其余角色以"被提到的名字"出现设定全留，出场分批
91 个小聚落 + 1 个母港让"选择性稳定"的道德重量存在

明确不在序章（但保留在设定池里）

空岛 · 旧主城 · 海底区域 · 表里世界 · 多势力 · 船战 · 船员系统 · 多城市 · 存在重量系统 · 4 个可玩职业 · 驯兽师独立单位

这些就是阶段 C 的更新内容。设定一个字都不删。

四、阶段 C（长线更新）怎么运作

#条件现在要做什么
1有一个已上线的版本B 阶段的目标就是它
2更新内容来自"已写好的设定"✅ 你们最大的优势——设定池很完整，内容不缺，只缺排期
3固定节奏每 3–6 个月一次内容更新，每次 +1 座岛或 +1 条支线（+30–60 分钟）
4有稳定玩家上线后才知道。第一条真实评论就是继续更新的燃料

更新内容的取用顺序（成本从低到高）：

  1. 新生态卡（复用已有骨架）← 最便宜
  2. 新支线 / 新 NPC
  3. 新岛屿（骨架复用）
  4. 新势力 / 新机制
  5. 空岛、旧主城、海底 ← 最贵，放最后

注意：在上线前不要承诺更新频率。 上线后再定节奏。

六、三条红线

  1. 🔴 不删设定。 所有"不做"都指"这一章不做"，永远不指"设定作废"。
  2. 🔴 不承诺日期。 对玩家、对彼此都不承诺发布日期；只承诺"每 3–6 个月有一次可见进展"。
  3. 🔴 不把项目和任何一个人的价值绑定。 做不完，不代表任何人失败。

七、风险与对策

#风险对策
1每样都做了一半铁律三：阶段验收不过不推进
2序章越做越大守住第三条那 9 项；任何"再加一点"都先砍掉等价内容
3长线更新没有玩家上线前不承诺频率；把"被看见"的最小单位定为一个陌生人玩过，不是"火了"
4后处理调优成瘾（HD-2D 特有）每个效果 ≤3 个参数、总共 ≤2 小时，然后冻结
5两人节奏不一致计划按"最低投入"排；任何一方的产出都不落在关键路径上
6倦怠允许长时间停摆。停两个月不叫失败，停两年才叫
