游戏底层核心逻辑 · 四个方案与一个合成方案

用途：确定 demo（2 座岛 + 1–2 职业）的底层循环。背景：两位作者此前在方向上存在分歧——一方主张高可玩性的战斗刷刷刷，另一方主张高表现力的电影化叙事与剧情。本文档的结论：这个分歧不需要折中，因为世界观里已经存在一个机制能同时供两边使用：翻面。

0. 先把分歧重新描述一遍（这一步很重要）

分歧通常被描述成"战斗 vs 剧情"，于是它看起来像是一道时间分配题——谁多一点，谁就少一点。

但它其实不是时间分配题，而是"什么是那个可重复的最小单元"的问题。

需要什么
刷刷刷一个可重复、且重复起来仍有变化的最小单元
电影化叙事不可重复、高密度、有分量的时刻

关键洞察：

如果让"重复的单元"本身产出"不可重复的东西"，两者就不再争夺同一条时间线，而是互相喂养。

而你们的世界观里恰好有一个机制天然就是这样：

翻面的性质服务的诉求
翻面 ＝ 世界状态切换 → 资源 / 敌人 / 地形全变 → 天然可重复（同一张地图，两份内容）她的"刷"
翻面 ＝ 灾难事件 + 道德抉择 + 不可逆后果 → 天然不可重复他的"叙事"

所以四个方案的区别，本质上是「翻面在这个循环里处于什么位置」。

1. 一个必须先说清楚的 demo 现实

在 60–120 分钟、2 座岛的 demo 里，做不出"练级到 99"式的刷。

"长周期数值积累"型的刷需要 40 小时的内容量才有满足感；2 座岛撑不起来。所以 demo 期的"刷"必须是：

✅ 应该是❌ 不应该是
短周期（每次 10–20 分钟）长周期（刷 10 小时才升一级）
高变化（每次敌人组合/结果不同）纯重复（同一套敌人打一百遍）
带决策（要判断撤不撤、值不值）纯点击（无脑按攻击）
roguelite 式"远征"MMO 式"练级"

这一条决定了后面所有方案的设计取向。

附带解决一个隐患：指令式战斗容易"重复到腻"

你们已定指令式战斗（这是最省的选择，我支持）。但指令式战斗重复起来比动作战斗更容易腻。三个解法：

  1. 敌人组合与弱点变化（由"图鉴 / 知识型进度"驱动——已定为主轴）
  2. 能量与平衡度的风险回报（见方案 C）
  3. 翻面切换敌人表（同一张地图两套敌人）

方案 C 恰好就是"让指令式战斗值得刷"的那个机制——这一点下面会展开。

2. 四个方案

每个方案的核心区别是：循环的心脏是什么。

方案 A · 翻面驱动：「远征」

一句话：每次翻面就是一次远征；玩家在翻面倒计时内进入岛屿，达成目标，然后世界改变。

项内容
核心循环接委托 → 备战（装备/船员/符文）→ 进入岛屿 → 在翻面倒计时内达成目标 → 翻面发生 → 世界状态改变 → 新资源新敌人 → 再来
重复单元一次远征（10–20 分钟）
变化从哪来翻面后同一座岛变成另一套生态/敌人/资源表——同样的地图，两份内容
目标多样性抢资源（贪）／救人（善）／稳定（智）／催化（恶）／打霸主（力）——同一个系统，五种动机
她的诉求✅✅ 刷的载体天然存在：两种状态各刷一次；目标多样，不是单纯打怪
他的诉求✅✅ 每次翻面都是事件：有前兆、有抉择、有不可逆后果
成本中（需要倒计时系统 + 备战系统）
风险翻面周期要做成"可玩节奏"：太慢刷不了，太快叙事没时间铺
demo 可行性高

方案 B · 航线驱动：「航段」

一句话：航线就是时间轴；每个航段推进剧情，抵达岛屿后进入箱庭。

项内容
核心循环选航线 → 航行事件（战斗/抉择/发现）→ 抵达岛屿 → 岛屿任务 → 回港 → 新航线
重复单元一次航段（5–15 分钟）
变化从哪来航线上的随机事件（海怪/风暴/浮岛/漂流物）+ 抵达后的岛屿任务
她的诉求✅ 航行事件可重复刷（海怪、资源点），但深度有限——需要有事件表支撑
他的诉求✅✅ 结构最清晰、天然章节化；演出可以集中放在"关键抵达"，性价比最高
成本最低（最像八方旅人，最容易做）
风险⚠️ 航行若做成过场就完全没得刷——必须做成"节点式 + 事件表"
demo 可行性最高

方案 C · 平衡度驱动：「代价」

一句话：战斗消耗的是本地能量；刷得越狠，世界越接近翻面。

项内容
核心循环战斗/施法 → 消耗本地能量 → 岛屿平衡度下降 → 生态失控 / 敌人变强 → 必须撤离或稳定 → 翻面 → 新状态
重复单元一次"探索 → 消耗 → 撤离"的循环（10–20 分钟）
变化从哪来玩家自己的行为在改变世界——同一个岛，因为你上次刷得狠，这次已经不一样了
她的诉求✅✅ "越刷越危险"制造了真正的风险回报张力——这才是让人想"再刷一次"的东西
他的诉求✅✅✅ 机制即主题：玩家的贪婪被直接写进世界状态。设定里"人类的手段本身在加速灾难"，在这里变成了可操作的规则
成本中高（数值平衡比 A/B 难）
风险⚠️ 只有惩罚没有解压阀 → 刷变成负担。必须给"稳定/撤离/庇护"作为解压阀
demo 可行性中——但最能展示这个世界观的独特性

为什么它值得优先考虑：它是四个方案里唯一一个"战斗系统本身在讲故事"的设计。她想要的"刷"在这里不是白刷，刷在写故事。

方案 D · 日志驱动：「记录」

一句话：玩家的"知识"就是进度轴；记录即变强。

项内容
核心循环探索 → 记录（海图/图鉴/怪物弱点）→ 获得锚定与情报 → 解锁新航线与打法 → 探索更深
重复单元一次发现（1–5 分钟，可以很碎）
变化从哪来收集与解锁；知识本身是进度
她的诉求✅ 收集型刷刷刷（图鉴全收、资源采集、词条解锁）
他的诉求✅✅ 玩家写下的字就是叙事；"航海日志"是密度最高、成本最低的叙事载体
成本低（已是既定方向：Q40 知识型进度为主轴）
风险⚠️ 单靠它会很"安静"，需要战斗与演出配合
demo 可行性高

3. 合成方案（本文档的推荐）

骨架 = B（航线）· 心脏 = C（平衡度）· 长线 = D（日志）· 高潮 = A（翻面远征）

四个方案不是四选一——它们处在循环的不同层级：

层级采用作用
骨架（怎么串联）B · 航线最稳、最易做、天然章节化；提供"抵达 → 演出"的挂点
心脏（为什么想再玩一次）C · 平衡度世界独有的张力；机制即主题；让指令式战斗值得刷
长线（玩 10 小时后还剩什么）D · 日志最便宜的长线目标；两个人都受益
高潮（每座岛的顶点）A · 翻面远征提供峰值体验：倒计时 + 抉择 + 不可逆后果

一句话说明这个合成为什么成立：

玩家沿着航线（B）抵达一座岛，在岛上探索与记录（D），用战斗解决问题——而每一次战斗都在消耗这座岛的能量（C）。当他消耗得足够多，这座岛会翻面（A）。而翻面之后，世界记得他做过什么。

在这个结构里，"刷"和"剧情"不是两件事，而是同一件事的两面。

配比建议（demo 期）

内容占比
战斗≈ 50%
探索与记录≈ 25%
叙事与抉择≈ 25%

⚠️ 但关键不在配比，而在这句话：

叙事不是"看演出"，而是"在战斗中/战斗后通过选择产生"。

过场动画是最贵的叙事手段；"因为你怎么打，所以故事变成这样" 是最便宜的。demo 期应该把钱花在后者。

4. 两座岛怎么承载这个平衡

这是把上面的理论落到具体关卡设计的一块。

岛 1 · 老家（教学 + 情感锚点）

项内容
目的教机制 + 让玩家在乎
内容走动 · 战斗基础 · 第一次"小翻面"（安全的、有预告的）· 1 个 NPC 关系 · 1 个小委托
配比叙事 40% / 战斗 35% / 探索 25%
关键设计这里的翻面是安全的（剧情保护），让玩家理解规则而不受惩罚
结尾老家发生一次玩家无法阻止的小翻面 → 情感钩子 + 推动出海
给谁这整座岛是给他的（情感与叙事密度）

岛 2 · 展示岛（完整机制 + 可刷内容）

项内容
目的展示这款游戏完整的样子
内容完整的平衡度系统 · 可重复的远征（2–3 种目标）· 可刷的资源点与敌人 · 一次大翻面事件（3 种解法） · 1 个 boss · 1 条支线 · 港口
配比战斗 50% / 探索 25% / 叙事 25%
关键设计可重复的远征（她的刷）+ 不可逆的抉择（他的叙事）同时存在
结尾玩家的选择改变岛的状态，而且不会恢复 → "世界记得你做过什么"
给谁这整座岛是给她的（可玩性与重复价值），同时用来证明"这个系统能撑起长线"

两座岛＝两种倾向各自主导一次。 这比"每座岛都五五开"更好：各自都有一个能证明自己的舞台，而且能看清对方的诉求长什么样。

5. 1–2 个职业怎么设计（让职业选择本身表达核心张力）

建议的两个职业不是"战士 vs 法师"这种数值差异，而是两种与世界的关系：

职业机制与世界的关系服务谁
职业 1 · 剑士（强化自身漩涡）低能量消耗、直接、数值成长清晰、靠自身变强改变自己她的"爽"：纯战斗向，刷起来有明确的变强感
职业 2 · 术士（调用能量）可施放影响岛屿平衡度的法术：抽取 / 稳定 / 催化改变世界他的"主题"：玩家能直接操作世界状态，机制即叙事

这个设计的好处：两个职业的差异不是"哪个伤害高"，而是"你要不要为力量负责"。玩家选职业时，其实是在选立场。

如果只做一个职业，推荐 职业 2 · 术士——因为它直接暴露这个游戏最独特的东西。如果做两个，职业 1 是给她的，职业 2 是给他的，正好再平衡一次。

7. 一句话总结

不要问"战斗多一点还是剧情多一点"。问"什么是那个让人想再来一次的单元，以及它能不能顺便产出故事"。在你们的世界观里，答案是：翻面。
