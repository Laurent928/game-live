一、现在就写的两条（不依赖她的新答案）

A2 · 倒下之后（玩法 V1.0 §七）—— 按 V1.2 第二十二条重写

玩法 V1.0 现在怎么写：§七——体力空 → 倒下 → 灵魂流失 → 附近有符文／队友／庇护所就能拉回来（损失资源、掉一段记忆）→ 独自倒在无人海域会被吃掉一部分 → 被世界之风侵蚀＝永久死亡。

V1.2 正文怎么写（第二十二条「失败的阶梯」原文五条）：

#正文原文要点
1人死后会掉落最能代表该角色的物件；玩家可以拾起这些物件
2在篝火或船上复活：船上无条件；篝火则需要用"无主的灵魂"加以融合，把蕴藏在物件中的人物的影子重新构造成完整——但有限制、会有所削弱
3无主的灵魂可以用来提升能力，也可以直接塑造成货币（与普通货币无异）
4存储：船上空间可以无限存放；下船以后的背包空间有限，不同素材与道具占用的空间各不相同，角色死亡后的道具也会强制占用空间
5船的系统：船上可以有各种物件（带特殊能力）；部分岛屿有"船坞"，可给船装配部件与地区特色部件

为什么必须改：三处对不上——① 复活条件（V1.0 是"符文／队友／庇护所"，正文是"篝火／船上"）；② V1.0 完全没有"掉落物件—拾取"这一层；③ V1.0 没有背包与存储规则。留着两套会让玩家拿到互相打脸的失败规则。依据：Q17 已在 2026-09-21 定案（08 §6.5：那份草案＝阿丞的总结、双方达成共识）；差异清单 A2。

回写要点（按正文五条逐条落，顺序即玩家实际遇到顺序）：

  1. 体力空 → 倒下（保留 V1.0 这一层）；
  2. 掉落最能代表该角色的物件，物件可被拾起；
  3. 复活分两种：船上无条件；篝火要用"无主的灵魂"融合（把物件里人物的影子重构完整）——有限制、会削弱；
  4. 无主灵魂：可提升能力、也可当货币；
  5. 存储：船上无限、下船背包有限、死亡后道具强制占空间；
  6. 船的系统：船上物件 ＋ 部分岛屿的船坞（部件／地区特色部件）；
  7. 被世界之风扭曲＝真死（保留 V1.0 这一层，与正文第二十条一致）；
  8. 🔵 玩家自己能不能被扭曲——要她定（差异清单 B3 / 02 Q17b，她没答过）。在定下来之前，回写稿里这一句留空、不写死。

A6 · 翻面前兆（玩法 V1.0 §五）—— 把"天"换成"阶段"

玩法 V1.0 现在怎么写：§五——翻面前 1–2 天天象变（云、星、潮水）、动物开始迁走；翻面前几小时地上出现裂缝、怪吼、植物变色；最后一段不给数字倒计时；翻面一瞬间。

V1.2 正文怎么写：

  • 第五条：翻面是可预测的自然周期，征兆包括天象异变、动物迁徙、异常现象与地貌变化；
  • 同条周期口径：翻面不按固定天数发生，而是"按星象"发生，各岛受影响的程度与时机各有差异；
  • 第六条给了可观察现象五条：海水退潮 · 动物提前迁徙 · 世界一瞬间安静下来 · 植物叶子发光 · 每座岛还可以有自己特有的几个反常现象；
  • 她的口径（21 G7）：星象与本地征兆共同判断；各岛不必然同时翻面或同时触发。

为什么必须改：V1.0 的整套节奏以"天"为单位；周期改成"按星象"之后，"前 1–2 天"没有落点（差异清单 A6）。

回写要点：

  1. 把绝对天数改成三个阶段（名字建议·未定案）：
    • 征兆期——天象异变、海水退潮、动物提前迁徙；
    • 异常期——植物叶子发光、地貌变化、该岛特有的反常现象；
    • 临界期——世界一瞬间安静下来 → 翻面；
  2. 预测口径写明星象 ＋ 本地征兆共同判断（她 G7）；
  3. "不给数字倒计时"这一条仍是助手草案（差异清单 A7：她没答过，"给不给"两边都是助手写的）→ 回写稿里标为待定，不写死；
  4. 绝对时长留空——她说《尺度表》数值暂不填写，等玩法成型（V1.2 附录B 10）。
