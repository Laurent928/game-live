二、你现在该做的三件事（按优先级）

🔴 第一件：阶段 0 —— 跟完一个教程，做到能打包（2–3 周）

做什么：找一个完整的 Unity 小游戏教程（2D 或 3D 都行，内容与你们的项目无关），跟着做完，做到能打包出一个可运行的程序。

为什么必须先做这个：零基础同时面对"学工具"和"做设计"两个未知，几乎必然卡死。先跟完一个别人的完整项目，你拿到的是工作流、C# 基础、打包流程——这三样之后每天都要用。

不要跳过。 详见 04-第一个月逐周清单.md。

🔴 第二件：阶段 1 —— 做出「一张截图」（2–3 周）

做什么：不写任何游戏逻辑，只做画面——一小块 3D 空地 + 2–3 个建筑 + 一个精灵角色 + 相机参数 + 三样后处理。

为什么它的优先级这么高：

  1. 它是这个项目唯一的高风险未知（"我们到底能不能做出八方旅人那个感觉"），越早验证越好；
  2. 它是给卿宝看的第一件东西——"看，我们的游戏长这样"。这一件事对信心的作用超过十份文档；
  3. 它同时确定了美术规格（精灵多大、色板多少、光照风格），之后所有人照着它做。

通过标准：把截图给不知情的人看，对方会说"这个像八方旅人那种"。

详见 02-技术与环境搭建.md §3 和 04-第一个月逐周清单.md。

🟠 第三件：报名游戏开发社团，排一个 Game Jam

社团是你的成长通道：它承担了"把东西做完"的压力，有反馈、有截止日、有同伴——这三样恰好是业余项目最容易缺的。学到的立刻用到本项目上。
