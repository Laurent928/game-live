02 · 技术与环境搭建

一次做对，之后不用再改。 这一份是"装好东西、建好项目、配好画面"的清单。HD-2D 的完整配方（含坑清单）在 世界观\01-设计与审查\07-HD-2D实践路线.md；这里只留动手要用到的部分。

一、一次性设置清单

#项具体做法为什么
1Unity 版本装一个 LTS（长期支持）版，把版本号写下来（例如 6000.x.y LTS），整个项目周期内不升级升级 Unity 是学生项目最常见的"工程突然打不开"原因
2渲染管线建项目时选 URP 模板（或后期升级到 URP）HD-2D 的"高级感"完全来自 URP 的后处理，这是硬性前提
3版本管理装 GitHub Desktop（图形界面），建一个私有仓库零基础不要用命令行 Git；但一定要用，否则丢工程是必然事件
4.gitignore用下面第七节的 Unity 版本否则仓库会被上百 MB 的缓存撑爆
5备份除 Git 外，每周把整个工程压缩一份放到另一个盘Unity 工程可能损坏
6记录版本号在仓库根目录放一个 PROJECT-INFO.txt，写上 Unity 版本 + 最后更新时间两个人用同一版本

⚠️ 两个人必须在同一个 Unity 版本上工作，否则场景文件会互相打不开。

│   ├── World/             翻面、平衡度、生态

│   └── Data/              SO 的类定义
└── Settings/              ★ URP Volume 预设、调色 LUT

三个星号的重点：

  • Data/：所有数值放这里。改平衡度、改敌人血量不用改代码、不用重新编译——这是新手能立刻受益的架构习惯。
  • Scenes/Test/：试验场。所有试错都在这儿做，不要把试验代码写进主场景。
  • Settings/：把 URP Volume 预设存成资产。"翻面"就是切换两个预设——这是最省力的实现方式。

三、HD-2D 起始参数表（照抄，之后再微调）

项起始值备注
相机类型Perspective（透视）⚠️ 不要用正交，否则退回纯 2D 观感
相机 FOV30°最重要的一个数。FOV 小 → 接近等距但保留深度
相机俯角约 40°（向下看）八方旅人式的斜俯视
相机距离12–16 单位配合 FOV 一起调
角色精灵高度64 px不要一上来做 128+
PPU（Pixels Per Unit）3264px 精灵＝2 个单位高
网格尺寸1 单位 = 1 格全项目统一，后期省无数麻烦
场景贴图128–256 px，Point filter，Tiling场景贴图也要低分辨率像素感，否则和像素角色不搭
色板限制 32–48 色，全项目统一风格统一最便宜的手段
点光源≤3 个（前期）后处理 + 多实时光源会掉帧

相机怎么调：先设 FOV 30、俯角 40、距离 14，然后只动距离——距离决定"看多远"，FOV 决定"透视有多强"。这两个调好，画面就有七成对了。

四、「高级感」的三根支柱（按性价比排序）

如果只做三件事，就做这三件。 它们能让"方块场景 + 像素小人"立刻看起来像有制作的样子。

优先级效果怎么做作用
①景深 Depth of FieldURP Volume → Depth of Field。Focus Distance ≈ 相机到角色的距离；Aperture 5–8最关键。远景虚化立刻产生电影感，是八方旅人观感的第一来源
②统一调色 Color GradingURP Volume → Color Adjustments / Tonemapping全场景统一氛围。成本≈0，效果极大
③Bloom（泛光）URP Volume → Bloom。Intensity 0.3–0.8，Threshold 0.9灯光、魔法、水面发光——夜晚场景的灵魂

第四样（可选但很值）：体积光 / 光柱。URP 不自带。最便宜的做法是手工搓：一个半透明锥体网格 + 渐变贴图，放在光源下方。效果够用，而且完全可控。

⚠️ 硬规则：每个效果只调 3 个参数，全部不超过 2 小时，然后冻结。后处理调优是 HD-2D 最大的时间黑洞。

五、光照：先别碰烘焙

阶段做法
前期（现在）实时方向光 + 2–3 个点光源。方向光给主光（偏冷），点光源给火把/灯笼（偏暖）。暖冷对比 = 氛围
中期场景固定后，再考虑 Lightmap 烘焙
永远不要一开始就上烘焙——新手最容易卡住，且场景一改就要重烤

一个小技巧：让角色投下阴影。Sprite 默认不投影，需要一个带 ShadowCaster 通道的 Sprite 材质。角色有影子对"真实感"的提升远超预期，投入却很小。

六、精灵与 3D 的排序（HD-2D 必踩的坑）

症状：角色被建筑挡住、或角色穿透墙壁显示在最前面。

根因：透明材质默认不写入深度缓冲。

解法（照做即可）：

  1. 精灵材质用 Alpha Cutout（Alpha Test），不要用 Alpha Blend —— 深度写入正常，遮挡问题自动解决。
  2. 相机固定角度（不旋转）时：把精灵直接旋转到与相机视平面平行，不需要 billboard 脚本。
  3. 只有相机需要旋转时，才加"始终朝向相机"的 billboard 脚本。
  4. 精灵导入设置：Filter Mode = Point、Compression = None、缩放用整数倍（否则像素会糊）。

八、明确不要碰的东西

不要碰为什么
HDRP为高端画面而生，对你们是灾难性复杂度
正交相机观感退回纯 2D，HD-2D 的意义就没了
自己写 Shader / Shader Graph前期一律用 URP 内置 + 后处理
DOTS / ECS为性能而生，本项目规模用不到
Timeline 做演出前期用不上，改起来慢
多人联机复杂度是单机的数倍
程序化地形生成与手工箱庭抵触，调试困难
频繁升级 Unity 版本工程打不开的头号原因
大量 Asset Store 插件插件之间会冲突；只引入解决当前问题的、且你看得懂的

九、可以放心学的东西

ScriptableObject（最重要）· Cinemachine（相机自动变好看）· ProBuilder（3D 快速搭场景）· 新输入系统 · URP Volume 后处理 · 免费资源站（Kenney / OpenGameArt / 免费音效库）· Application.persistentDataPath + JSON 存档。
