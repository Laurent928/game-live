Q11 · 团队与工时（前置条件 · 待共同确认） · 共同

这是全部产能测算的输入。以下是规划用的工作假设，不是对任何一方的评价；两位看过之后都可以改。

项规划假设
团队2 人，创作与实现并行推进
有效投入每周合计约 10–14 小时（非全职；两人都还有学业与生活，投入会有波动）
引擎Unity
基础两位都是初次接触游戏制作，处在学习阶段
项目目标以学习为主；产出目标定为"能做完，并让别人玩到"

这个前置条件直接决定了三件事（详见 03 §1、§2）：

  1. 全部计划的产能基数＝ 10–14 小时/周 ≈ 500–700 小时/年；
  2. 任何一方的时间投入都不应成为关键路径——缺任何一块产出，游戏也必须能完整跑通；
  3. 评价标准从"什么时候做完"改为"每 2–3 个月有没有一个能玩/能给人看的东西"，并且允许项目永远不到终点。

连带修订：推荐终点从"3–5 小时短篇"下调为 30–60 分钟微型成品；路线图改为 L0–L3 阶梯（03 §5）；新增新手指南（03 §8）与协作规则（03 §9）。

Q11e · 游戏视角与美术风格 ✅ 已定：HD-2D（类八方旅人） · 卿宝 ⭐

为什么必须最先答：这是零基础团队成本影响最大的单个美术决定。它同时锁定美术侧的工作量上限和程序侧的难度。

选项难度（阿丞）难度（卿宝）说明
A · 2D 俯视（像素或手绘）最低中教程最多，零基础最快出成果
B · 2.5D 等距（斜 45°）中最高等距素材最难画，不推荐
C · 3D 低多边形中低场景用免费资源，美术侧只做立绘/UI/图标；最能保留"海洋与岛屿"的体量感
D · 3D 写实 / 第一人称高极高不做（03 §12.1 第 12 条）

建议默认答案：A 或 C（见 04 问卷第 1 题，可两位一起定）。想保留大海的开阔感 → C；想最快看到成果 → A。成本影响：★★★★ 影响面：美术 / 程序 / 全部场景资产

Q12 · 核心体验：这个游戏的一句话是什么？ · 共同

为什么必须答：所有后续取舍都取决于这句话。

请从下面 4 个核心情绪里选 1 个（或排序）：

  1. "看着熟悉的世界在我面前变成陌生的样子"（敬畏 / 失落）
  2. "我在和世界抢时间、抢资源、抢人"（紧迫 / 经营）
  3. "我在一片漂亮又危险的海上漂流"（自由 / 探索）
  4. "我在决定哪些人值得活下去"（道德 / 权力）

建议默认答案：①为主 + ④为辅。理由：①最贴合"翻面"这个独创机制；④的成本几乎为零（只需要在翻面窗口事件里给玩家两难选择）。而②③需要大量系统与资产支撑。成本影响：★★★★（选 ② 会引入经营系统；选 ③ 会引入自由航行与大量海洋资产） 影响面：全局

Q13 · 目标形态与时长 （v2 已重算） · 共同 ⭐

为什么必须答：它直接决定"世界观实现到什么程度才算完成"。

选项内容你们实际的耗时（含学习期系数 ×2–3）
A 3–5 小时短篇世界观作为背景，讲一个完整故事1700–5200 小时 ≈ 3–8 年 ❌ 已排除

D · 先不设终点做到哪个 L 阶段算哪个，每站都是可停下的作品灵活，风险最低

建议默认答案：C 为主目标 + D 为心态。即：以 L3（30–60 分钟微型成品）为方向，但把每一站（L0/L1/L2）都当成可以停下来的完整成果。理由：非商业化 + 学习导向下，唯一有意义的成功标准是"做完并被人玩到"。而"做完"在这个产能下只能是微型成品。成本影响：★★★★ 影响面：全局

Q14 · 两面的空间模型（对应 R1） · 共同

为什么必须答：这是地图设计的物理前提。不定义就无法开始制作任何一张图。

选项内容优点代价新手难度
A · 图层叠置岛＝上下两层；翻面＝上下位交换。海底区域＝里层地形；蓝洞＝可从表层物理进入里层的通道盘活"海底探索/深潜/蓝洞"三样已有设定需定义两层连通规则中
B · 硬币翻转字面翻转，另一面朝下没入水中最直观与"空岛"打架低
C · 相位共存两面同空间不同相位，常规手段不可互达最玄妙把"同时存在"变成纯修辞低

建议默认答案：A · 图层叠置（长期正解）。但 L0/L1 阶段可以先按 B 的简单做法实现——因为 L0 只需要"按一个键，世界变了"，两层的连通规则可以等到 L2 再定义。同时请顺带决定：是否废弃"表里世界/镜海"这套独立术语，并入"表／里两面"？（建议是）成本影响：★★★★ 影响面：地图 / 美术 / 程序

Q15 · 翻面周期量级（对应 R2） · 阿丞

为什么必须答：周期决定了这是纪元级叙事游戏还是赛季级循环游戏，也决定"可预测性"这个玩法是否成立。

选项内容结果
A · 单层短周期所有岛翻面周期＝数周至数月变成刷状态/资源管理游戏
B · 单层长周期所有岛翻面周期＝数十年至数百年变成叙事游戏，一辈子赶上几次翻面
C · 双层（推荐）小岛/浅层＝数周至数月（可玩、可干预、可催化）；大陆块/主城级＝数十年至数百年（主线事件，只发生一次）两种体验共存，且解释旧主城为何极其特殊

建议默认答案：C · 双层。数值建议：小岛 4–12 游戏周；主城级 100 年+。L2 的落地：只需 1 个周期值（这座岛还有几天翻面）+ 一个倒计时 UI。成本影响：★★★ 影响面：策划 / 玩法 / 数值

Q16 · 航行：可玩系统，还是过场？（对应 R3） · 阿丞 ⭐

为什么必须答：这决定这个游戏是不是"航海游戏"。文档第三条明写"航行本身为线性过程"，但它同时列了航线风险物、风暴变向、硬闯风暴、船员打海怪、船只改造——这些在线性过场里没有容身之处。

选项内容新手难度
A · 纯过场选航线 → 加载 → 抵达极低
B · 节点式航行（推荐）在海图界面上选航线、配置船员与货物、处理沿途事件；已探索航线可一键快进低（本质是 UI + 事件表，没有实时驾驶）
C · 手动驾驶实时操船、海况、风向、海怪追逐、登船战极高（已列入不做清单）

建议默认答案：B · 节点式航行，并把现有条款里的"线性过程"改写为"已探索航线可自动驾驶"——这样"线性"从世界的性质降级为可选的无障碍功能，设定与产能同时得救。注意：L0–L2 阶段完全不做航行（用"点击海图上的岛 → 切场景"代替）。航行是 L3 的内容。成本影响：★★★ 影响面：程序 / 策划 / 美术

Q17 · 死亡与失败阶梯（对应 R9） · 共同 ⭐

为什么必须答：第二十二条"此世之人理论上永生"是当前最大的设计债务——它把"失败"这个最基础的游戏反馈取消了。但修好它只需要一条规则。

建议采用的损失阶梯：

受伤 → 躯体消散（可复活，但需要有承载者）→ 灵魂受损（记忆缺口、能力丢失）→ 被扭曲（唯一真死） → 沦为憎恶（变成别人的敌人）

关键补充：灵魂若无人收集，会被别的存在吸收，或自行汇入憎恶。

  • Q17a 是否采用上面的损失阶梯？（建议：采用）
  • Q17b（共同） 玩家角色能否被扭曲？（建议：能。否则"世界之风"的威胁不可信。可做成真实的失败结局，或只在最高难度永久。）
  • Q17c 是否有"死亡但灵魂被人夺走"的情形？（建议：有）

建议默认答案：全部采纳建议。L1 的极简落地：死亡 → 掉落部分资源 + 一句"记忆缺口"文本 → 在最近庇护点复活。三行规则就能立住。 成本影响：★★（改动极小，收益极大） 影响面：程序 / 策划 / 文案
