# 玩法设定 V1.0

> **这份是什么**：把这款游戏**具体怎么玩**写出来——具体到"玩家按哪个键、岛上会发生什么"。
> 它不是选项题，是一份**草案**。目的是先有一个东西可以看、可以嫌、可以改。
>
> **为什么要写这么具体**：之前那两版问卷问的是"你想要什么感觉"，那种问题答不出来。
> 这份反过来——**我们先把方案写出来，你只需要说"这块对/这块不对/我想改成那样"。**

---

## 一、你是谁

你是**航海士**。有一艘船（师傅给的，很破）。

你身上有一样别人没有的东西：**你能感觉到一座岛稳不稳**。
就像老水手能感觉到天气要变一样——你站在岸上，就知道这座岛离翻面还有多久。

这个能力让你能提前做准备。但它也让你无法假装看不见。

---

## 二、你在游戏里具体做七件事

| # | 做的事 | 具体是什么 |
|---|---|---|
| 1 | **掌舵** | 在海图上点一个目的地，开过去。路上会有事（天气、海怪、漂来的东西） |
| 2 | **上岸** | 在岛上走动，和人说话，进屋子、下洞 |
| 3 | **探** | 找资源、找遗迹、找路。有些东西只在特定时候出现 |
| 4 | **打** | 遇到怪就打。**指令式**——选攻击、技能、道具 |
| 5 | **施** | 用"风"。这是你唯一的法术资源，**从脚下的土地里吸** |
| 6 | **记** | 把见到的记进航海日志：岛的形状、特产、怪物、航线 |
| 7 | **选** | 关键时刻做决定。有些决定改不回来 |

---

## 三、战斗具体是什么样

**指令式**。回合或半即时，敌人多的时候按速度排顺序。

每个回合你能选四件事：

- **普通攻击**（不耗"风"）
- **技能**（耗一点体力，不耗"风"）
- **用"风"**（很强，但会抽干脚下的地——见第四节）
- **道具 / 撤离**

**敌人有弱点**：怕火、怕水、怕风、怕打、怕砍。
打中弱点会**打断**敌人的动作——所以"试弱点"本身就是玩法。

你有两条槽：
- **体力**（会掉血，会死）
- **风**（施法资源，用完就没了，得回岸上补）

> **序章只有你一个人**。后面会有伙伴（一人一回合，可以换人）。

---

## 四、核心机制：「风」和平衡度

**这是这款游戏跟别的 RPG 最不一样的地方。**

每座岛有一个数字：**平衡度**，0 到 100。

| 平衡度 | 岛的状态 | 玩家能感觉到的 |
|---|---|---|
| 70–100 | 正常 | 天亮、风平、人和动物都正常 |
| 40–70 | 开始不稳 | 天色偏灰、鸟开始往别处飞、有些地方起雾 |
| 10–40 | 生态失控 | 怪变强、出现异常现象、地面开裂、植物变形 |
| **0** | **翻面** | 整座岛变成另一个样子 |

**你在岛上做的事会让平衡度往下掉：**

| 你做的事 | 掉多少 |
|---|---|
| 用"风"施法 | **掉得多** |
| 大量杀生 | 掉一点 |
| 把一片资源点采空 | 掉一点 |
| 打赢盘踞在岛上的霸主 | **掉很多** |

**什么能让它涨（解压阀）：**

- 找到并修复符文
- 把采走的东西还回祭坛
- 完成"稳住这座岛"的支线

> **于是产生一个真正的两难**：
> **用"风"你就打得过，但岛会更快翻面；不用"风"，你可能根本过不去。**
> 这不是道德说教——这是每次战斗都要做的算术。

---

## 五、翻面会发生什么（具体到每一步）

翻面**不是突然的**，它有过程：

| 时间 | 发生什么 |
|---|---|
| **翻面前 1–2 天** | 天象变（云、星、潮水）；动物开始迁走 |
| **翻面前几小时** | 地上出现异常现象：裂缝、怪吼、植物变色 |
| **最后一段** | 只有天象和氛围，**不给数字倒计时**。玩家得自己判断 |
| **翻面** | **一瞬间**。地貌、生态、怪、资源，全换 |
| **翻面之后** | 没躲进庇护所的人会被扭曲；外面的人会受伤 |

**躲哪里能保住命**：符文旁边、地标附近（那里像暴风眼，中心是静的）。

## 六、一座岛的"两个面"具体长什么样

举展示岛的例子：

| | **A 面（翻面前）** | **B 面（翻面后）** |
|---|---|---|
| 地貌 | 长满密林，有条河 | **干燥的沙漠**，河床干了 |
| 村子 | 下游小村，人靠打渔采药 | 只剩残墙 |
| 地标 | 岛中心一座**符文塔** | **半截埋在沙里的塔尖** |
| 能拿到的东西 | 药草、木材、鱼 | **地下的古代遗迹**（A 面拿不到） |
| 怪 | 林间的兽 | 沙里的东西 |

**两面都在的那一个东西**：村口那棵枯树。
A 面它是绿的，B 面它是焦的。**玩家靠它认出"这还是那座岛"。**

---

## 七、倒下之后会怎样

- 体力空了 → 倒下
- 倒下后**灵魂还在，但开始流失**
- **附近有符文 / 队友 / 庇护所** → 能拉回来。损失一些资源，掉一段记忆
- **独自倒在无人海域** → 灵魂流失，被附近的什么东西吃掉一部分。**会丢东西**
- **被"世界之风"侵蚀而死** → **永久死亡**。这是这个世界唯一的真死

> 意思是：**普通战斗输了不致命，但输在海上是要付账的。**

---

## 八、你怎么变强

**两条路，都要走。**

**第一条：数值**
等级、装备、素材。靠打怪和探。

**第二条：记录**（这条更重要）
你记下的东西会变成能力：

| 你记下什么 | 你就得到什么 |
|---|---|
| 一座岛的航线 | 以后可以直航，省时间、少遇险 |
| 一种怪 | 能看到它的弱点和剩余血量 |
| 一座岛的地形 | 地图上会标出资源点 |
| 一条海流 | 航行更快，能走原来走不了的路 |

> **记下的东西越多，你在那片海上越"稳"。**
> 因为这个世界靠"被记住"来确认自己存在——**你写下它，它就还在。**

## 九、序章具体长什么样

### 岛 1 · 老家（约 20 分钟）

1. **开场**：你在修船。师傅走过来，说了一句话，把船给你。
2. **教学**：走动、对话、采集。教你怎么看岛稳不稳。
3. **第一次战斗**：海边几只小怪。教指令式战斗和弱点。
4. **第一次翻面（安全的）**：师傅带你去岛的另一头，你亲眼看到一小片地貌翻过去。天变了一下，又变回来。**只是看，不会受伤。**
5. **回村，夜里。**
6. **第二天早上，码头那边翻面了。** 这次是**你无法阻止的**。师傅为了护住符文塔没回来。
7. **你上船，出海。**

### 岛 2 · 展示岛（约 40–60 分钟）

1. **抵达**。港口。接第一个委托。
2. **自由探索**：村子、密林、河、符文塔遗迹。可以采集、可以打怪、可以和人聊天。
3. **发现岛在变得不稳**（天象开始变了）。
4. **关键事件**：
   - 村里人求你帮他们**修符文塔**，把岛稳住。
   - 同时，一支外来商队想让你帮他们**催翻面**——因为翻面后地下会露出遗迹，那值很多钱。
5. **你选**：帮村里人 / 帮商队 / 谁也不帮，只拿走自己要的
6. 无论选什么，**最后都会翻面**（或者差点翻面），岛变成另一个样子。
7. **世界记住你的选择。** 下次回来，村子还在，或者不在了。

## 十、一整章的走法（这就是游戏循环）

> **出海 → 航程（路上有事）→ 抵岛 → 上岸探 → 遇到人和事 → 打 → 岛开始不稳 → 做决定 → 翻面 → 岛变样 → 带着变化回港 → 下一个目的地**

每一座岛，就是一章。

---

## 十一、她之前想要的那些东西，分别放在哪

| 她想要的 | 这份草案里怎么安排 |
|---|---|
| **大 RPG** | 一座岛＝一章，一路更下去，不砍 |
| **长线更新** | 每次更新加一座岛或一条支线 |
| **做给别人看的** | 序章就是可发布的第一章 |
| **战斗刷刷刷** | 翻面前 / 翻面后**两套怪和资源** → 同一座岛有得刷 |
| **电影化叙事** | **每次"翻面"就是一场演出**，是全章的高潮 |
| **很多角色** | 序章出场 2 个，其他以"被提到的名字"出现，设定全留 |
| **空岛、多势力、多结局** | 序章只做远景/2 个结局，其余排队，一个不删 |
