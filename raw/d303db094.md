# 04 · 第一个月逐周清单

> **这是最具体的一份。** 每一周都写了"做什么、验收什么、卡住怎么办"。
> **用法**：做完一项就打勾。**不要提前做后面的周**——第 1 周只需要干第 1 周的事。

---

## 第 1 周 · 把环境装好，让 Unity 跑起来

**目标**：不写代码，只把工具链弄通。

| ☐ | 任务 | 说明 |
|---|---|---|
| ☐ | 装 **Unity LTS**（Hub + 编辑器 + 一个 LTS 版本） | 装完**把版本号记下来** |
| ☐ | 建一个 **URP 模板**项目（名字随便，比如 `Test01`） | 确认模板里带 URP |
| ☐ | 打开项目，随便拖一个 Cube 进场景，点运行 | 确认能跑 |
| ☐ | 装 **GitHub Desktop**，注册/登录，建一个**私有**仓库 | |
| ☐ | 把 `02-技术与环境搭建.md` §7 的 `.gitignore` 存到仓库根目录 | |
| ☐ | 第一次提交（Commit）并推送（Push） | |
| ☐ | 在仓库根目录放 `PROJECT-INFO.txt`，写上 Unity 版本 | |
| ☐ | 找一个完整的 Unity 小游戏教程，**只看开头，确认它讲得清楚** | 建议选 2D 入门或 3D 入门小游戏 |

**验收**：Unity 能打开项目、能运行、代码已经推到 GitHub。

**卡点**：
- Unity Hub 下载慢 → 换时间段，或挂着下
- 不确定选哪个 LTS → **选列表最上面的 LTS 就行**，不要选标着 "Beta/Preview" 的
- Git 不懂概念 → 只需要记住三件事：**Commit＝存档，Push＝上传，Pull＝下载别人的改动**

---

## 第 2 周 · 跟完教程，做到能打包 🎯 **第一个里程碑 M1**

**目标**：做出一个**能打包运行的完整小游戏**（内容与你们的项目无关）。

| ☐ | 任务 |
|---|---|
| ☐ | 跟着教程做完前 1/2，能运行 |
| ☐ | 跟着教程做完全部，能运行 |
| ☐ | **改一个数值**（速度、血量、颜色），确认自己能看懂那一行代码 |
| ☐ | **把项目打包成可执行文件**（File → Build Settings → Build） |
| ☐ | 在文件夹里**双击运行打包出来的程序** |
| ☐ | 把它 Commit + Push |
| ☐ | 录一段 15 秒视频，发给卿宝 |

**验收**：**你能独立打包出一个别人双击就能运行的程序。** 这是这一周唯一的目标。

**为什么这周最重要**：它把"我什么都不会"变成"我做出来了一个能跑的东西"，而且你拿到的是**工作流**——之后每天都要用。

**卡点**：
- 打包报错 → 90% 是没选对平台或场景没加进 Build Settings。**先只加一个主场景**试试。
- 教程里用的 Unity 版本和你不一样 → 没关系，绝大多数 API 没变；实在找不到按钮就搜一下
- **看不懂代码是正常的**。这一周的目标是"跑通"，不是"理解"

---

## 第 3 周 · 建自己的项目，搭出第一个 3D 场景

**目标**：为你们的游戏建**真正的工程**，并搭出一小块空地。

| ☐ | 任务 | 说明 |
|---|---|---|
| ☐ | 新建一个 URP 项目，名字比如 `IslandGame` | **这次的版本要和第 1 周完全一致** |
| ☐ | 按 `02-技术与环境搭建.md` §2 建好 `Assets/` 目录结构 | 先建空文件夹就行 |
| ☐ | 新建 Git 仓库、放 `.gitignore`、首次提交 | |
| ☐ | 装 **ProBuilder**（Package Manager） | 用来在 Unity 里直接搭 3D 场景 |
| ☐ | 用 ProBuilder 搭：**一块 20×20 的地面** + 2 个方形建筑 + 1 个斜坡或台阶 | 形状丑没关系 |
| ☐ | 找一张**低分辨率像素贴图**（128 或 256 px）贴上地面和建筑 | 免费素材站有 |
| ☐ | 导入一个**像素角色精灵**（先用免费素材或 AI 占位图） | 64 px 左右 |
| ☐ | 把精灵放进场景，**缩放到约 2 个单位高** | 记住：1 单位 = 1 格 |
| ☐ | 存成场景 `Scenes/Test/Scene01` | 试验场 |

**验收**：场景里有地面、有建筑、有一个像素小人站着。

**卡点**：
- ProBuilder 不会用 → 只需要学三个操作：**画形状、拉伸、贴图**。教程 20 分钟够
- 精灵看起来糊 → 导入设置里 **Filter Mode 改 Point、Compression 改 None**
- 贴图重复得很怪 → 调整材质的 **Tiling** 数值

## 第 4 周 · 做出「那张截图」🎯 **里程碑 M2**

**目标**：**不写任何逻辑**，只调画面——让这一屏看起来像八方旅人。

| ☐ | 任务 | 起始值 |
|---|---|---|
| ☐ | 相机设为 **Perspective** | — |
| ☐ | **FOV 调到 30** | 最重要的一个数 |
| ☐ | 俯角调到 **约 40°**，距离 **14** | 只动距离，别动 FOV |
| ☐ | 加 **Directional Light**（偏冷色，比如淡蓝白） | 主光 |
| ☐ | 加 **2 个 Point Light**（偏暖色，放在建筑旁当火把） | 暖冷对比 |
| ☐ | URP Volume 里加 **Depth of Field** | Focus ≈ 相机到角色的距离，Aperture 6 |
| ☐ | URP Volume 里加 **Color Adjustments** | 对比度 +，饱和度微降，整体偏暖或偏冷（**统一**） |
| ☐ | URP Volume 里加 **Bloom** | Intensity 0.5，Threshold 0.9 |
| ☐ | 给角色**开阴影**（用带 ShadowCaster 的 Sprite 材质） | 提升远超预期 |
| ☐ | 加一点点**粒子**（漂浮光尘） | 可选但很值 |
| ☐ | **截图，存下来，发给卿宝** | **这就是交付物** |

**验收**：把截图给一个不知情的人看，对方会说"**这个像八方旅人那种**"。

**⚠️ 硬规则**：每个后处理效果**只调 3 个参数，全部不超过 2 小时**，然后**冻结**。调优是最大的时间黑洞，第一版只要"有那个感觉"就够了。

**卡点**：
- 画面很平 → 八成是相机还是正交，或者 FOV 太大
- 后处理没效果 → Volume 要设成 **Global**，且相机要勾选 Post Processing
- 角色被建筑挡住 → 精灵材质改 **Alpha Cutout**（见 `02` §6）
- 调了很久还是不像 → 检查**色板是否统一**、**贴图是不是也低分辨率**。HD-2D 的统一感来自"场景和角色一样粗"

## 如果整周什么都没做成

**这不叫失败，这叫正常。** 处理方式：

1. 把没做完的那一项**拆小一半**再做一次；
2. 如果还是做不动 → 说明这一步**依赖了你还不会的东西**，回去补那个前置（比如：ProBuilder 不会用，就先花 30 分钟只学 ProBuilder）；
3. **不要跳过它去做后面的**——欠的账一定会回来。
