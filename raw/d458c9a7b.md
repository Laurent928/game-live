## 四、规矩（与主工作区一致，这里再写一遍）

| 规矩 | 要点 |
| --- | --- |
| **不许跳读** | 读不完就分段读**完**；万不得已跳过，**当轮**写清"哪一段（行号）/ 多少行 / 为什么 / 风险"四件事 |
| **每条带出处** | 文件 ＋ 行号；**引文照抄**，不改写、不合并 |
| **先比对** | 任何"新增设定 / 新词 / 与正文冲突"，先跑 `_工程\工具链\比对\crosscheck.cjs`，并写明查过哪里 |

| **先挂账后升版** | 不在正文上直接改；**但本线不另起、不尝试更新的版本**（阿丞 2026-09-22：「**以最新版本为准；版本里没有再尝试其他较新版本**」）。`01-设计与审查\21-V1.3-修订要点（挂账）.md` 是**邻线的记录**，本线只读、不推进 |
