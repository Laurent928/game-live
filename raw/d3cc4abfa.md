# 部署说明 · 把问卷变成永久公网网址

> **这个文件夹里只有一个文件：`index.html`**（就是问卷本身）。
> 它被命名为 `index.html`，是为了让部署后的根网址直接打开问卷，不需要带文件名。
> （此处内容涉及个人隐私，已隐藏）

---

## 为什么需要另外部署

| 方式 | 网址 | 有效期 | 手机能开 | 需要账号 |
|---|---|---|---|---|
| 局域网（`05-问卷与部署\启动问卷服务器.bat`） | `http://172.19.35.120:8788/` | 电脑开着 + 同一 WiFi | ✅ | 不需要 |
| **Cloudflare 临时隧道** | `https://xxx.trycloudflare.com` | **电脑关了就失效，重启会换地址** | ✅ | 不需要 |
| **部署到静态托管（本文档）** | `https://xxx.netlify.app` 等 | **永久** | ✅ | **免费账号** |

结论：**发给她慢慢填** → 用本文档的方式部署；**只是现在想给她看一眼** → 用隧道地址就够。

---

## 路线 A · Netlify Drop（最快，推荐）

1. 电脑浏览器打开 **https://app.netlify.com/drop**
2. 把这个 `05-问卷与部署` 文件夹**整个拖进**页面中间的虚线框
3. 几秒后它给出一个网址，形如 `https://random-name-123456.netlify.app`
4. 想长期保留，用邮箱/ GitHub 免费注册一下，就能在后台改名、固定地址

> 特点：不用命令行、不用装东西。适合"我只想赶紧拿到一个链接"。

---

## 路线 B · GitHub Pages（如果你有 GitHub 账号）

1. 新建一个仓库，例如 `island-questionnaire`，**设为 Public**
2. 把 `index.html` 上传到仓库根目录（网页上「Add file → Upload files」即可）
3. 进 **Settings → Pages**，Source 选 `Deploy from a branch`，Branch 选 `main` + `/ (root)`，保存
4. 等 1–2 分钟，网址是 `https://你的用户名.github.io/island-questionnaire/`

> 特点：永久、免费、以后更新只要覆盖 `index.html`。缺点：仓库是公开的（内容本身也只有问卷）。

---

## 路线 C · Cloudflare Pages

1. 打开 **https://pages.cloudflare.com**，用邮箱注册（免费）
2. 选 **Upload assets**（直接上传，不用连 Git）
3. 把 `05-问卷与部署` 文件夹拖进去，项目名随便填
4. 得到 `https://项目名.pages.dev`

> 特点：速度快（国内访问通常比 GitHub Pages 稳），永久。

---

## 部署完之后

1. 用手机（**QQ 里**）打开那个网址试一次：能正常显示题目、点选项有反应、点「生成回传链接」能出链接。
2. 把网址发给她。QQ 里点开就能填。
3. **如果 QQ 内置浏览器显示异常**，让她点右上角「···」→「在浏览器打开」。
4. 她填完 → 点「📤 分享给 QQ / 微信」直接发回来，或者点「复制这段文字」再粘贴回来。

---

## 更新问卷内容

问卷改过之后（比如又加了题），重新生成一份：

1. 用最新的 `01-设计与审查\04-互动问卷.html` 覆盖本文件夹里的 `index.html`；
2. 回到托管平台重新拖一次 / 重新上传。

她之前填的答案不会被覆盖（答案是存在**她手机浏览器里**的，不在这个文件里）。

---

## 关于隐私

- 页面已加 `<meta name="robots" content="noindex, nofollow">`，**搜索引擎不会收录**；
- 但网页本身是**公开**的：**任何拿到链接的人都能看到内容**。内容里出现了"阿丞""卿宝"两个名字，以及游戏设计的问题；
- 链接是随机生成的，不会被猜到，正常使用没问题；如果介意名字，可以让我把两个名字替换成中性词再部署一版。
